# Product

## Users and promise

Anyone in Bangladesh who sees a civic problem can report it in under a minute, in Bangla or English, without ever revealing who they are. Neighbours see what is happening around them; authorities (phase 2) get routed, verified reports.

## Core flows

1. **First run:** splash → 3 onboarding screens (language switch on every screen) → mobile number → SMS code → NID + date of birth → allow location.
2. **Report:** tap the red camera button → take a live photo → pick a category (big icon tiles) → write a short description → location is filled in automatically → choose whether to show your alias → post.
3. **Stay aware:** Nearby / Latest / Following feeds, category filters, awareness tips, live heat map with tappable hotspots, notifications.
4. **Trust:** "I see it too" confirmations, report-this-post flags, status timeline (Reported → Acknowledged → In progress → Resolved).
5. **Motivation:** XP, 8 levels, 34 badges, anonymous weekly/monthly/all-time leaderboard, follow citizens by alias.

## Accessibility

Bangla by default with English one tap away; Bangla digits throughout; in-app text size (Normal / Large / Extra large) on top of the system setting; 48dp+ touch targets; icons always paired with labels; screen-reader labels on custom controls; dark mode.

## Roadmap

- **Phase 2 — authorities:** zone boundaries, automatic routing to the responsible councillor / chairman / mayor / thana OC / ASP, authority logins and dashboards (web + mobile) to acknowledge and resolve, public response-time statistics per area.
- Push notifications (FCM), offline drafts, short video evidence, duplicate detection by location + category, NID verification via Porichoy.
